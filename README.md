# 🏥 MediScan AI – End-to-End Medical Diagnosis System

MediScan AI is an **end-to-end machine learning healthcare application** that provides multiple disease predictions through a single, unified interface.  
The system is designed with **scalability, memory optimization, and real-world deployment** in mind.

---

## 🚀 Live Application

🔗 **Live URL**  
👉 https://mediscan-ai.onrender.com

> Note:  
> The **Breast Cancer Detection module** is hosted separately on Hugging Face Spaces to handle large deep-learning models efficiently, while other ML models run on Render.

---

## 🧠 Features

### ✅ Diabetes Prediction
- Input-based ML prediction
- Trained using structured medical data

### ✅ Heart Disease Prediction
- Multi-parameter risk analysis
- Fast real-time inference

### ✅ Parkinson’s Disease Detection
- Voice & signal-based feature prediction
- High-accuracy classical ML model

### 🩺 Breast Cancer Detection (Image-based)
- Deep Learning (DenseNet121)
- Ultrasound image classification
- Hosted on Hugging Face for better memory handling

---

## 🏗️ System Architecture

- **Frontend & Core ML Services**: Streamlit + Render
- **Heavy DL Model (Image Classification)**: Hugging Face Spaces
- **Model Types Used**:
  - Random Forest
  - Classical ML classifiers
  - CNN (DenseNet121)

---

## ⚙️ Tech Stack

- **Languages**: Python
- **Frameworks**: Streamlit, Gradio
- **ML/DL**: Scikit-learn, TensorFlow, Keras
- **Deployment**: Render, Hugging Face Spaces
- **Data Handling**: NumPy, Pandas
- **Model Serialization**: Pickle, HDF5 (.h5)

---

## 📌 Key Highlights

- End-to-end ML lifecycle (data → training → deployment)
- Real-world memory optimization strategy
- Production-ready architecture
- Clean UI with seamless user experience
